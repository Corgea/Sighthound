# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Open source release: LICENSE, CI, CONTRIBUTING, SECURITY, and community docs
- `examples/basic_scan.rs` library usage example
- GitHub Actions CI and release workflows

## [0.1.1] - 2025-06-11

### Added

- AST-based vulnerability scanning with search and taint analysis modes
- Embedded RON rules for Python, JavaScript, TypeScript, Java, Go, C#, Ruby, PHP, and HTML
- Auto-detection scan mode with parallel processing
- JSON, CSV, and text output formats
- Cross-file taint analysis (best-effort)
